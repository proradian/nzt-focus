# Focus — приложение

Код программы: `src/` — интерфейс (HTML/CSS/JS без сборщика), `src-tauri/` — нативная часть на Tauri 2.

Описание, сборка и лицензии — в [README.md](../README.md) в корне репозитория.

```powershell
npm install
npx tauri dev     # запуск в режиме разработки
npx tauri build   # установщик в src-tauri/target/release/bundle/nsis/
```
